# LangChain Projects

This repository contains a collection of simple AI projects built while learning **LangChain, LLMs, Cohere, Gemini, Streamlit, and document-based AI**.

## Projects

### 1. Blog Generation
Generates a blog based on a given topic, number of words, and target audience.

### 2. Conversational Q&A Chatbot
A chatbot that answers questions and remembers the conversation.

### 3. Calories Health
Upload a food image and get information about the food and estimated calories.

### 4. Chat with Multiple PDFs
Upload multiple PDF files and ask questions about their content.

### 5. LLM Generic App
A basic application demonstrating how an LLM can be connected to an application.

### 6. Q&A Chatbot Using LLM
A simple chatbot that uses an LLM to answer user questions.

### 7. Text Summarization
Summarizes a given speech or text and can generate the summary in a selected language.

## Technologies Used

- Python
- LangChain
- Cohere
- Google Gemini
- Streamlit
- FAISS
- Jupyter Notebook

## How It Works

Most projects follow a simple process:

**User Input → LangChain → AI Model → Response**

For document-based projects:

**PDF → Text Extraction → Text Chunks → Vector Search → AI Response**

## Note

API keys are stored locally in `.env` files and are not included in this repository.

## Purpose

This repository was created for learning and practicing **Generative AI and LangChain application development**.
